# Security Policy

Report suspected security or privacy issues privately to `election@anmore.me` with the subject “Anmore Votes security report.” Do not include passwords, authentication codes, or unrelated personal information.

The public site intentionally has no sign-in, public submission form, analytics, advertising pixel, or behavioural tracking. Retired submission endpoints return HTTP 410. Candidate and community correspondence is handled outside the public website.

Please allow reasonable time to investigate before publicly disclosing a vulnerability. Reports are handled under the privacy and corrections policies at https://anmore.me/legal/.

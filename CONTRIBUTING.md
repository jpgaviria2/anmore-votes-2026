# Contributing

This repository is public for transparency, but election content is held to a higher standard than ordinary website edits.

- Technical and accessibility fixes are welcome through pull requests.
- Candidate content must come through the verified candidate-submission workflow.
- Community questions must use the moderated question form.
- Pull requests must not endorse, oppose, rank, or disparage a candidate.
- New factual claims require a reliable public source.
- Never add private contact information, home addresses, nominators, or unverified social profiles.

See [EDITORIAL_POLICY.md](EDITORIAL_POLICY.md) before proposing content changes.
